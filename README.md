# personal-Budgeting

#Welcome to the personal budgeting app where you can store your incomes, expenses, budgets and set reminders for any bill you have.

#The app is built in C#, you must have .NET 9 or newer to run it. The app also stores its data in the local sql server, the default SQL server on your machine must be running and you must run the SQL script located in the project files before running the app.
